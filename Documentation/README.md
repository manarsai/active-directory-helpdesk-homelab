## Exercise 1: Creating a new employee account in Active Directory

Tools Used:
- Windows Server 2025
- Active Directory Users and Computers
- Active Directory Domain Services
  
Procedure
1. Logged into Windows Server domain controller (DC01)
2. Opened Server Manager
3. Selected Tools and opened Active Directory Users and Computers
4. Expanded the northstar.local domain
5. Opened Users Container
6. Selected New -> User
7. Entered New User Sarah Jones and created user name sarah.jones
8. Set an initial password and option requiring user to change password at next logon

## Exercise 2: Resetting an employee's password

Procedure
1. Opened Server Manager
2. Selected Tools and opened Active Directory Users and Computers
3. Expanded the northstar.local domain
4. Opened Users Container
5. Found Sarah Jones
6. Selected Reset Password
